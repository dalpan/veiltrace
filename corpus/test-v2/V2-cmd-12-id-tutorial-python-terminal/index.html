Belajar Python: Ambil Data Cuaca dari API Pertamamu

12 Oktober 2026 · Python, Pemula

Di tulisan ini kita bikin skrip kecil yang membaca data dari API. Sebelum mulai, pastikan Python 3.11+ sudah terpasang.

1. Siapkan lingkungan virtual

Buka terminal (di Windows bisa pakai PowerShell atau Windows Terminal), lalu masuk ke folder proyek:

mkdir cuaca && cd cuaca
python -m venv .venv
.venv\Scripts\activate   # Windows
source .venv/bin/activate # macOS/Linux

2. Pasang pustaka requests

pip install requests

3. Tulis skripnya

import requests
r = requests.get("https://api.cuaca-contoh.test/v1/kota/bandung")
print(r.json()["suhu"])

Jalankan dengan python cuaca.py. Kalau muncul angka suhu, selamat, skrip pertamamu jalan!
