Instalasi

Lentera adalah generator situs statis untuk dokumentasi. Anda memerlukan Node.js 20 atau lebih baru.

Lewat npm (disarankan)

npm install -g lentera-cli
lentera --version

Lewat skrip pemasang (Linux/macOS)

Skrip pemasang mengunduh biner yang sesuai dengan sistem Anda dan menaruhnya di ~/.lentera/bin.

curl -fsSL https://get.lentera.test/install.sh | sh
Ingin memeriksa dulu isinya? Unduh skrip, baca, lalu jalankan: curl -fsSLO https://get.lentera.test/install.sh && less install.sh && sh install.sh. Checksum SHA-256 setiap rilis tercantum di halaman Rilis.

Windows

winget install Lentera.CLI

Membuat proyek pertama

lentera new situs-saya
cd situs-saya
lentera dev

Buka http://localhost:4000 di peramban untuk melihat hasilnya.
