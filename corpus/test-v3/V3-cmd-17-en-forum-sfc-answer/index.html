Windows Update stuck at 0% for two days

Tried restarting several times. Any ideas?

Accepted answer · 214 votes

Run the built-in repair tools. Open Command Prompt as administrator and run these one at a time:

sfc /scannow
DISM /Online /Cleanup-Image /RestoreHealth

Both ship with Windows and only repair system files. Reboot afterwards and retry the update.

Worked for me, thanks.
