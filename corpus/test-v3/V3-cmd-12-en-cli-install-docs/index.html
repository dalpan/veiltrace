Installation

Quillstack requires Node.js 20 or newer. Check your version first:

node --version

Install from npm

npm install -g quillstack

Build from source

git clone https://git.quillstack.example.invalid/quillstack.git
cd quillstack
npm ci
npm run build

Verify the install with quillstack --help. If you hit permission errors on Linux, see Troubleshooting rather than using sudo.
