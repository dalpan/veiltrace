Praktikum 3: Virtual Environment & Pandas

Tujuan: mahasiswa mampu menyiapkan lingkungan Python terisolasi.

Langkah

  1. Buka Terminal (Mac/Linux) atau PowerShell (Windows).
  2. Buat environment: python -m venv .venv
  3. Aktifkan: .venv\Scripts\activate (Windows) atau source .venv/bin/activate
  4. Pasang paket: pip install pandas==2.2.3

Kumpulkan tangkapan layar hasil pip list di e-learning paling lambat Jumat.
