Fake "I'm not a robot" pages are tricking people into infecting their own PCs

By M. Ortega · Oct 20, 2026

Researchers say a wave of compromised websites now shows a bogus verification box. When visitors tick it, the page quietly copies a command to the clipboard and displays something like:

"Press Windows + R, then Ctrl + V, then Enter to complete verification."

Doing so runs a PowerShell downloader. "No real CAPTCHA will ever ask you to open the Run box," one analyst told us.

What you should do

  • Close the tab if a site asks you to paste anything into Run, Terminal or PowerShell.
  • Organizations can restrict the Run dialog through policy.
