3 Cara Cek IP Address di Windows 11 (Mudah untuk Pemula)

Ditulis oleh Fajar · 12 Sep 2026

Cara 1: Lewat Command Prompt

  1. Tekan tombol Windows + R untuk membuka kotak Run.
  2. Ketik cmd lalu tekan Enter.
  3. Ketik ipconfig dan tekan Enter.
  4. Lihat baris IPv4 Address, misalnya 192.0.2.15.

Cara 2: Lewat Settings

Buka Settings > Network & Internet > Properties.

Catatan: perintah ipconfig hanya menampilkan informasi dan tidak mengubah apa pun.
