Install the Contoso CLI

On macOS and Linux, open a terminal and paste the following command, then press Enter:

curl --proto '=https' --tlsv1.2 -sSf https://sh.contoso.test/install.sh | sh

On Windows, download the installer from the releases page.

Troubleshooting

If the installer fails with a permissions error, re-run it with sudo.
