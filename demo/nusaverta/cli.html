Install the Nusaverta CLI

Version 3.2 · Updated last week

The CLI lets you export invoices and reports from scripts and scheduled jobs.

macOS and Linux

Open Terminal and run the install script:

bash
curl -fsSL https://get.nusaverta.example.invalid/install.sh | sh

Windows

Open PowerShell and run:

PowerShell
irm https://get.nusaverta.example.invalid/install.ps1 | iex

Check the installation

Run nusaverta --version. It prints the installed version, for example 3.2.0.
